## English

### Overview

Scholarship Hunter is a product concept for AI-powered global scholarship discovery and application intelligence. Its intended experience helps applicants find opportunities that reflect their circumstances, understand eligibility, prepare practical next steps, and stay oriented through applications and deadlines.

### Product direction

The visible product direction calls for:

- Applicant-aware discovery of global scholarship opportunities.
- Clear explanations of eligibility.
- Practical readiness guidance and support for applications and deadlines.
- A premium yet approachable, human, purposeful experience—not a generic dashboard.

These points describe the intended direction, not features implemented in this repository.

### What this repository provides

This repository provides a reusable AI skill and product-building guide, not a deployed scholarship service or an implemented platform. It does not include a live scholarship inventory or a working application.

The guide is in [`skills/scholarship-hunter/SKILL.md`](skills/scholarship-hunter/SKILL.md).

### Use the guide

Open the skill file, then copy or install the `skills/scholarship-hunter/` folder using the mechanism supported by your AI environment. Installation steps depend on that environment. This repository is not packaged as an application or extension.

### Scope and source limits

The product specification available for this work was visibly truncated. This README and the companion skill preserve that limitation: they summarize only the requirements that were visible and do not claim to reproduce unseen details.

## Bahasa Indonesia

### Gambaran umum

Scholarship Hunter adalah konsep produk berbasis AI untuk pencarian beasiswa global dan dukungan informasi pendaftaran. Pengalaman yang dituju membantu calon pendaftar menemukan peluang yang sesuai dengan keadaan mereka, memahami kelayakan, menyiapkan langkah praktis, serta mengikuti proses pendaftaran dan tenggat.

### Arah produk

Arah produk yang terlihat mencakup:

- Pencarian beasiswa global yang mempertimbangkan keadaan calon pendaftar.
- Penjelasan kelayakan yang jelas.
- Panduan kesiapan yang praktis serta dukungan untuk pendaftaran dan tenggat.
- Pengalaman premium yang tetap ramah, manusiawi, dan bertujuan—bukan dasbor generik.

Poin-poin ini menggambarkan arah yang dituju, bukan fitur yang telah diimplementasikan di repositori ini.
